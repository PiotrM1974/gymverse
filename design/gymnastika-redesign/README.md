# GymNastika 2.0 — koncepcje interfejsu

Etap projektowy zakończony 23.11.2026. Pliki w tym katalogu nie są częścią produkcyjnej aplikacji. [Wykaz akceptacji](approvals.md), [specyfikacja końcowa](design-handoff.md) i [oddzielna instrukcja wdrożenia](implementation-instruction.md) opisują zatwierdzony zakres.

Wybrany kierunek „Mineral Track”: spokojne powierzchnie i mocna typografia. Zatwierdzony wariant kolorów „Signal” używa wyrazistego niebieskiego dla głównych działań, pomarańczu dla Push, turkusu dla Pull i żółci dla oznaczenia następnego planu. Kolory MuscleMap pozostają semantycznie niezależne. Wcześniejsze plansze są zachowanymi alternatywami.

Kolejka: ekran startowy → aktywny trening (serie, timer, ilustracja, MuscleMap, nagłówek kompaktowy) → podsumowanie → historia → statystyki → progres ćwiczeń → edycja planów → panele pomocnicze i komunikaty. Każdy etap wymaga osobnej akceptacji.
