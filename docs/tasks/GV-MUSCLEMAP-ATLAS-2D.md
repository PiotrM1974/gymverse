# GV-MUSCLEMAP-ATLAS-2D

## Zakres udzielonego zlecenia

Wklejona prośba użytkownika upoważnia do audytu aplikacji GymNastika 2.0 i
MuscleMap w trybie odczytu, przygotowania lokalnego prototypu atlasu 2D dla
czterech ćwiczeń oraz raportu. Istniejące PR #4–#7 mają pozostać bez zmian. Nie
scalać, nie wdrażać, nie publikować, nie modyfikować Master Prompt ani danych
treningowych.

## Wymagania

- Przyjąć MuscleMap 2D jako podstawę atlasu; wcześniejsze prace 3D traktować
  jedynie jako zarchiwizowany materiał referencyjny.
- Uwzględnić sylwetki męskie i żeńskie, przód i tył oraz ID ćwiczeń:
  `lat_raise_stand`, `db_bench`, `lat_pulldown_wide`, `leg_press`.
- Użyć czerwieni `#F04438` dla obszarów głównych, złota `#F3B544` dla
  pomocniczych i neutralnego grafitu dla pozostałych.
- Oddzielić diagramy od rekordów treningowych, zachować działanie offline,
  dołączyć licencję i pochodzenie zasobów oraz opisać ograniczenia mapowania.
- Zatrzymać się po dostarczeniu raportu.
