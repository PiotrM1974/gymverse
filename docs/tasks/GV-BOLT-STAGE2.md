# GV-BOLT-STAGE2

Autoryzacja właściciela: etap 2, wyłącznie wygląd nagłówka, zachowanej nawigacji i rzeczywistych kart planów. Systemowy motyw pozostaje domyślny; ręczny wybór działa w bieżącej karcie. Bez integracji wierszy, timera, generatora, profili, kopii, historii lub ilustracji. Przed kolejnym etapem wymagana osobna zgoda.
