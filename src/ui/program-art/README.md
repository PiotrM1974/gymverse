# Program artwork — generated 3D library

Six decorative program covers, generated for GymNastika on 2026-11-26 with the built-in image generation tool. They do not represent exercise technique and do not replace the approved exercise/variant registry.

The owner approved the blue bench reference and requested different equipment, colour variations and a random selection for each new program/plan. Generated PNG originals are retained locally; these self-contained WebP files are the runtime assets. Conversion: 384 × 384, WebP quality 0.90, alpha preserved. No third-party image or logo was used.

## Prompt set

Shared direction: premium photorealistic 3D product render for a small fitness-app thumbnail; square composition, complete product and generous margins; transparent alpha background; graphite steel, brushed silver and royal-blue accents; soft studio lighting, realistic tactile materials and a refined contact shadow; three-quarter view, legible at 90 px; no text, logos, people, room or floor.

Subjects:
- Flat bench with blue upholstery, graphite rack, silver barbell and round plates; natural proportions.
- One dual-pulley cable machine with graphite frame and blue panels, no bench or other equipment.
- Only two compact adjustable round-plate dumbbells with short silver handles and blue collars; no bench, long bar, rack or other gear.
- Only two kettlebells, a large blue one and a small graphite one, realistic thick handles; no other equipment.
- One 45-degree leg-press machine with coherent rails, a large footplate, blue seat, graphite frame and weight plates; no additional gear.
- One loaded Olympic straight bar, silver grip, blue collars/plate centres, diagonal composition, plus two spare plates; no bench, rack or kettlebell.

## Presentation and limits

`../program-art.js` derives a reproducible random seed from the existing random program/plan identity and profile identity. No new storage key, data-model field or training-data write is introduced. Eight soft card colour families are selected independently. Normal refresh, theme changes, assignment and renaming do not reroll the icon or card colour.

Canonical stored program order (before active-first sorting) resolves collisions between 1,296 equipment/colour combinations. This covers the supported collection of up to 200 programs plus 1,000 plans. Appending a program preserves preceding program covers. Deleting/reordering/importing collection entries can reassign a collision-resolved icon; this is cosmetic only. At high collection counts some neighbouring colour shades are visually close. Card backgrounds can repeat, as there are eight colour families. No claim of infinitely many unique images.

All six images and the selector are included in the existing Service Worker shell. They need no external network service. Exact exercise thumbnails still resolve by exerciseId and variantId.
